MISES A JOUR EN LIGNE - HAYTHEM FOOD

A FAIRE UNE SEULE FOIS
1. Publiez ce dossier sur un hebergeur gratuit (Netlify Drop, Cloudflare Pages ou GitHub Pages).
   Exemple Netlify : app.netlify.com/drop, puis glissez le dossier decompresse.
2. Sur chaque borne, ouvrez l'adresse obtenue (https://...) et installez l'application.
   L'application ne doit pas etre ouverte depuis un fichier copie sur l'appareil.

NOTE : config.json est deja dans ce dossier. Publiez-le a cote de index.html.

POUR CHANGER LE MENU, LES PRIX, LES PHOTOS OU LE BANDEAU
1. Modifiez-les dans Admin sur UNE borne.
2. Admin > Reglages > Mises a jour en ligne > Exporter config.json.
3. Envoyez config.json sur votre site, a cote de index.html, en remplacant l'ancien.
4. Toutes les bornes le reprennent seules (toutes les 10 minutes par defaut),
   a l'ecran d'accueil, jamais pendant une commande.
   Photo en ligne : dans config.json, mettez "img":"img/kefta.jpg" et envoyez le fichier dans le dossier img/.

POUR AMELIORER L'APPLICATION
Remplacez index.html (et sw.js) sur votre site. Chaque borne redemarre seule a l'ecran d'accueil.

NE CHANGENT JAMAIS : historique des commandes, code PIN, imprimante, paiements, langue.
Attention : le menu de config.json remplace celui des bornes (une categorie absente du fichier est retiree).

- Chaque commande validee sur la borne est envoyee au meme serveur (Supabase) que le site.
  Elle apparait sur l'ecran cuisine (haythemfood.com/#cuisine) et sur l'ecran clients
  (haythemfood.com/#file), avec le meme numero que sur le ticket de la borne.
- Cuisine : se connecte comme avant (e-mail + mot de passe). Rien a changer sur le site.
- Paiement carte / Payconiq : la cuisine voit "Carte · borne". Especes : "Especes" + "a verifier"
  (a encaisser au comptoir).
- Sans internet : la commande est gardee et renvoyee toute seule (toutes les 30 s). L'ecran de
  confirmation affiche un avertissement rouge "Cuisine non prevenue" tant que ce n'est pas fait.
  Dans ce cas le numero du ticket est un numero local ; le numero cuisine s'affiche ensuite
  dans Admin > Commandes ("cuisine N°x").
- Reglages : Admin > Reception > "Ecrans cuisine & clients" (activer/desactiver, ticket test,
  boutons pour ouvrir les deux ecrans).
